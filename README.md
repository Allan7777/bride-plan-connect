# Your Wedding Hub

Quero que você construa um Micro-SaaS completo chamado provisoriamente de "NoivaHub".

IMPORTANTE:

Não quero apenas uma landing page.

Quero uma aplicação web funcional, moderna, responsiva e preparada para produção.

O produto será um SaaS + marketplace de fornecedores para casamento.

A ideia central é:

"Planeje seu casamento, organize tudo e encontre os fornecedores certos em um só lugar."

Existirão dois públicos pagantes:

1. NOIVAS

2. FORNECEDORES

Ambos terão assinatura de R$ 10,90/mês.

==================================================

1. VISÃO DO PRODUTO

==================================================

Não quero criar simplesmente um "site de fornecedores".

Quero criar uma plataforma de planejamento de casamento.

A NOIVA entra na plataforma para:

- organizar o casamento;

- acompanhar o que já resolveu;

- descobrir fornecedores;

- pesquisar fornecedores;

- favoritar fornecedores;

- entrar em contato;

- controlar seu planejamento;

- acompanhar o progresso do casamento;

- futuramente receber recomendações inteligentes.

O FORNECEDOR entra para:

- criar uma vitrine profissional;

- divulgar seus serviços;

- mostrar portfólio;

- ser encontrado pelas noivas;

- receber contatos;

- receber leads;

- acompanhar visualizações;

- acompanhar oportunidades.

Portanto:

NOIVA = planejamento + descoberta

FORNECEDOR = divulgação + geração de oportunidades

PLATAFORMA = conexão entre os dois.

==================================================

2. PROPOSTA DE VALOR
